# YouTube Clone

This project is a static clone of the YouTube homepage, created using HTML and CSS. It serves as a front-end exercise to replicate the visual layout and design of the YouTube interface.

## Features

- **Header Section**: Includes the YouTube logo, a search bar with a search button, a voice search button, and user-related icons for video upload, apps, notifications, and user account.
- **Sidebar**: A navigation sidebar with links to Home, Explore, Subscriptions, Originals, Shorts, and Library.
- **Video Grid**: A responsive grid layout displaying video thumbnails, titles, authors, and stats.

## Getting Started

To view the project, simply open the `youtube.html` file in your web browser. No special setup or dependencies are required.

```bash
# Open with your default browser
open youtube.html
```

## HTML Structure

The `youtube.html` file is structured into three main parts:

- **`<header>`**: Contains the top navigation bar with the logo, search functionality, and user icons.
- **`<nav>`**: The sidebar, which provides links to different sections of YouTube.
- **`<main>`**: The main content area, which features a grid of video previews.

## Styling

The project is styled using CSS. The following CSS files are linked in `youtube.html` but are currently missing from the repository:

- `styles/general.css`: General styles for the page.
- `styles/header.css`: Styles for the header section.
- `styles/video.css`: Styles for the video grid and its elements.
- `styles/sidebar.css`: Styles for the sidebar.

The project uses various images and icons, which are located in the `youtube pictures/` and `icons/` directories. These include:

- **Thumbnails and Profile Pictures**: Stored in `youtube pictures/`.
